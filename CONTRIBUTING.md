# Contributing

The contributor guide lives in [`docs/contributing.md`](docs/contributing.md). It covers local
setup, scripts, the project layout, architecture, adding a chapter, the release pipeline and the
art pipeline.

Quick start:

```bash
npm install
npm run dev
npm run typecheck
npm test
```

Open issues and pull requests against the repository. For player-facing fixes, see
[`docs/troubleshooting.md`](docs/troubleshooting.md).
